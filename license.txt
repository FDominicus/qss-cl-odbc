qss-cl-odbc -- license

qss-cl-odbc is derived from plain-odbc by Roland Averkamp. It consists of
- the code of Roland Averkamp (2005), with changes by QSS / Friedrich
  Dominicus (2026): src/odbc/package (formerly plain-odbc-package), global,
  ffi-support, parameter, column, odbc-main, odbc-utilities;
- new code by QSS / Friedrich Dominicus (2026): src/odbc/odbc-library,
  dates, odbc-calls, the generated src/odbc/odbc-api-generated, tools/,
  src/test/qss-tests and the *.asd files of the generator and the tests;
- the ODBC header files of Microsoft in odbc-headers/ (MIT license, see
  odbc-headers/LICENSE-Microsoft.txt). They are used to generate
  src/odbc/odbc-api-generated.lisp and are not needed to use qss-cl-odbc;
- the Chinook sample database of Luis Rocha in src/test/chinook/ (MIT
  license, see src/test/chinook/LICENSE-Chinook.md), used by the tests and
  by doc/examples/chinook-tour.lisp; the expected values in expected.sexp
  come from the Chinook test suite.

Both parts by Roland Averkamp and by QSS are under the (new) BSD license
below, each with its copyright notice.

History: until 2026 the lowest layer of plain-odbc (constants, foreign
function declarations and their wrappers) came from Paul Meurer's SQL/ODBC
module (1999-2001) under his own license. On 2026-10-14 it was replaced by
declarations generated from Microsoft's ODBC headers and by newly written
code (see qss-patches.txt); no code of that layer remains. David Owen
adapted plain-odbc to 64-bit Linux. On 2026-11-03 the QSS version was
renamed from plain-odbc to qss-cl-odbc (system and package QSS-CL-ODBC),
so that it can live next to the original.
